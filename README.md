# Jennifers sportsbutik – opgave A, B, C og D

Åbn index.html med Live Server, eller brug https://jennifermiwanpia.github.io/opgave-a-produktliste/. Internet kræves til kategorier, produkter og billeder fra https://kea-alt-del.dk/t7/.

- Opgave A: productlist.html, productlist.js og productlist.css viser en dynamisk produktliste.
- Opgave B: productdetails.html, productdetails.js og productdetails.css viser det produkt, man klikker på i listen. Produktets id sendes i URL'en og bruges til at hente ét produkt fra API'et.
- Opgave C: index.html, index.js og index.css viser API'ets kategorier. Et klik sender kategorien i URL'en til produktlisten, som henter produkter i den valgte kategori.
- Opgave D: Produktlisten og detaljesiden viser Tilbud med rabatprocent, førpris og tilbudspris, når discount er sat. Udsolgte varer markeres med Udsolgt og et gråt billede, når soldout er sat. Et produkt kan have begge markeringer.

Hvis et produkt ikke kan hentes, vises en fejlbesked og en Prøv igen-knap. Åbnes detaljesiden uden id, henviser den tilbage til produktlisten.
